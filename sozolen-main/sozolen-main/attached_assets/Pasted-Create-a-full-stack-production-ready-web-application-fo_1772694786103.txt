Create a full-stack production-ready web application for a small business that creates custom 3D models from customer photos.

Business Workflow:
Customers provide photos and requirements. The business creates custom 3D models using Autodesk tools and delivers them manually. Customers can also browse previously created models.

The checkout process will NOT use any payment gateway. Instead, when customers finalize their order, the website should send all order details to a WhatsApp number (9876543210) so the business owner can manually communicate with the customer.
